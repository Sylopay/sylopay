# Introduction

Welcome to the **SyloPay BNPL** smart contract documentation book. 

This interactive documentation guide details the decentralized credit terms mechanism implemented in Rust on the Stellar Soroban network.

Use the left sidebar navigation menu to browse the detailed pages:
*   **Overview & Architecture**: Structural overview of the modular directories and the hybrid storage class decisions.
*   **Data Structures**: Technical definitions of Enums and Structs.
*   **Core API Functions**: Actionable endpoints for contract initialization, creation, repayment, and administrative controls.
*   **Security Matrix**: Signature validations and explicit authorization controls.
